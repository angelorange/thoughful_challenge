# Thoughtful IA Challenge

This repository is a challenge that consists of automating the process of extracting data from a news site.

## The process
- The main steps:

- Open the site by following the link

- Type a phrase into the search field

- On the results page

- If possible, select a news category or section in the field

- Choose the most recent news (i.e. most recent)

- Get the values: title, date and description.

- Store in an Excel file:

- title

- date

- description (if available)

- image file name

- count of search phrases in the title and description

- True or False, depending on whether the title or description contains any amount of money

- Possible formats: $11.1 | $111,111.11 | 11 dollars | 11 USD

- Download the news image and specify the file name in the Excel file

- Follow steps 4 to 6 for all news items that fall within the required time period

## Tools used
- Python
- Robocorp
- Selenium
